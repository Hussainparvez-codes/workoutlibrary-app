# FitLog — Workout Library

FitLog is a modern dark-themed workout library built with Next.js. It allows users to explore workouts, view detailed exercise information, build a daily workout plan, save favorite workouts, and track their progress through a clean and responsive interface.

## 🚀 Technologies Used

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Lucide React
- React Toastify
- REST API
- JavaScript / JSX
- Local React Context API

## ✨ Key Features

### 1. Workout Library
Browse a collection of workouts with useful information such as exercise name, muscle groups, equipment, duration, calories, and rating.

### 2. Workout Details
Each workout has a dedicated details page with a large workout image, description, muscle tags, equipment, difficulty, sets, reps, duration, calories, rating, and step-by-step instructions.

### 3. Today's Workout Plan
Users can add workouts to their daily plan and keep track of their selected exercises. The plan supports a maximum of 5 lifts.

### 4. Save Workouts
Users can save workouts for later and easily access them from the Saved section of the My Plan page.

### 5. My Plan & Progress Tracking
The My Plan page shows today's exercises along with total exercises, workout minutes, and calories. Users can view workout details, mark exercises as done, remove workouts, and sort them by duration, calories, or rating.

## 📱 Responsive Design

FitLog is designed to work smoothly across:

- Mobile devices
- Tablets
- Laptops
- Desktop screens

## 🎯 Project Goal

The goal of FitLog is to provide a simple and focused workout management experience where users can discover exercises, organize their daily routine, and save workouts they want to revisit.
